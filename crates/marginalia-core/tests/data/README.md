Small KF8 test books, converted with calibre's `ebook-convert` from EPUBs
written for these tests (`illus*`: original text and drawings; `kieu`:
the opening of Nguyễn Du's *Truyện Kiều*, public domain).

- `kieu.azw3`: KF8 only, two chapters, Vietnamese.
- `illus.azw3`: KF8 only, one chapter with an inline picture and a cover.
- `illus-both.mobi`: hybrid file (MOBI 7 + KF8) of the same book.
